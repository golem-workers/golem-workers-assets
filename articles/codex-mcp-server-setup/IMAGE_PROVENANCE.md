# Image provenance

All four images in this directory were generated as original raster artwork with OpenAI image generation on 2026-07-18 for the article `codex-mcp-server-setup`.

- `codex-mcp-server-cover.webp` — dedicated article cover; Codex workflow connected to external tools through a secure gateway.
- `codex-mcp-server-skill-boundary.webp` — workflow instructions separated from the MCP capability layer.
- `codex-mcp-server-tool-policy.webp` — least-privilege tool allowlist and approval checkpoint.
- `codex-mcp-server-validation.webp` — connection, read, approval, and completion validation path.

The generated PNG sources were first normalized to 1200×675 WebP assets. On 2026-07-23, the dedicated cover was re-normalized to 1280×720 and the two body images used by the production article were re-normalized to 960×540 to satisfy the current article media contract. The imagery remains derived from the original raster generations; no SVG, HTML, CSS, canvas, or programmatic diagram source was used.
