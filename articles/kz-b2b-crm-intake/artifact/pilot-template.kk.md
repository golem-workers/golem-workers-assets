# CRM пилотының паспорты

- CRM, режимі, API нұсқасы, тарифі және қолжетімділігі:
- Рұқсат етілген дереккөз/қалта; ұйым; тұрақты оқиға ID-і:
- Мақсатты нысан және рұқсат етілген өрістер:
- Мәтіннен / конверттен / ережеден алынған және белгісіз өрістер:
- Сәйкес жазбаларды іздеу; оқу құқықтары; бірнеше сәйкестік табылғандағы әрекет:
- Нақты пакетті кім мақұлдайды және жазуға кім рұқсат береді:
- Жауапты қызметкер; мерзім ережесі және уақыт белдеуі:
- Журнал: кілт, hash, reviewed, lead_confirmed, task_confirmed, completed/unknown:
- Әр бөлек жазу операциясының белгісіз нәтижесін қалай салыстырып тексеру керек:
- Тыйым салынған әрекеттер: баға белгілеу, клиентке хат жіберу, кезеңді өзгерту, біріктіру, жою:
- Деректерді сақтау/жою мерзімі/қолжетімділік/модель ортасы:
- Қабылдау: сегіз сценарий және нақты иесіздендірілген RU/KK мысалдары:
- Шекті көрсеткіштер: өріс қателері, жоғалған өтінімдер, қайталанатын жазбалар, қолмен жұмыс істеу уақыты, ерекше жағдайлар:
- Жұмысты тоқтатуға/ақауды түзетуге және команданы оқытуға жауапты адам:

Жергілікті сынақ мысалы деректерді модельмен алмайды және CRM-ге жазбайды. Жұмыс адаптеріне істен шыққанда да сақталатын деректер қоймасы, бірегей кілт және қатар жазудан қорғаныс қажет. Мысалдағы барлық деректер синтетикалық; example.invalid — жұмыс істейтін байланыс мекенжайы емес.
