# Өрістер мен ерекше жағдайлар паспорты

Кіріс төлем шоты мен шарт талабы үшін жасалған оқу жинағы. Клиент деректері, заң сараптамасы немесе төлем нұсқауы емес.

- Тексеруге жауапты адам: ______
- ID, бет, бастапқы үзінді: ______
- Бастапқы мән / біріздендірілген мән: ______
- Тексеру ережесі / нәтиже / себеп: ______
- Жеткізуші мен банк өзгерісін тексеру: ______
- Ықтимал қайталау / салыстырылатын нұсқа: ______
- Келесі әрекет / жауапты адам: ______
- Тыйым салынған әрекеттер / сақтау мерзімі: ______

## DEMO-CONTRACT-09-r1

DEMO-CONTRACT-09-r1, 2-бет, 4.2-тармақ: «қабылдау актісіне қол қойылғаннан кейін10 жұмыс күні ішінде». Акт күні мен келісілген жұмыс күнтізбесі жоқ. Есептелген күн:null; мәртебе CLARIFY_DEADLINE. Жауапты қызметкер қолданылатын нұсқа мен қосымшаларды тексеруі керек.

## Жағдай → күтілетін бағыт

- 1. Дереккөзі тексерілген дұрыс жинақ → `READY_FOR_HUMAN_REVIEW`
- 2. Басылғаны148000, жолдар140000 → `AMOUNT_MISMATCH`
- 3. 14O000 санындағы O әрпі → `CHECK_NUMBER`
- 4. Жеткізуші жоқ → `MISSING_FIELD`
- 5. Сол шоттың басқа сканы → `CHECK_DUPLICATE`
- 6. Валюта жоқ → `MISSING_FIELD`
- 7. KZT орнына USD → `CHECK_CURRENCY`
- 8. Мерзімнің басталу оқиғасы белгісіз → `CLARIFY_DEADLINE`
- 9. Банк деректемелері өзгерген → `VERIFY_BANK_CHANGE`
- 10. Дереккөз тексерілмеген → `CHECK_SOURCE`
