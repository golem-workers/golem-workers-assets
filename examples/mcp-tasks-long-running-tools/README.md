# MCP tasks fixture

Dependency-free Node.js 22 policy harness for the MCP 2025-11-25 experimental tasks lifecycle. It demonstrates capability checks, task creation, polling, authorization-context isolation, input-required resume, completion, failure, cancellation, TTL expiry, and deferred result retrieval.

This is not a complete MCP server or an official SDK implementation.

```bash
npm ci
npm test
npm run demo
```
